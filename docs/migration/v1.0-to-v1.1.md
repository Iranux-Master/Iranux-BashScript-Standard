# Migrating Iranux Scripts from v1.0 to v1.1

## Summary

Version 1.1 adds required UI library metadata. It does not change parameter blocks, Bash logic, certification semantics, or the final runtime marker.

## Migration steps

1. Remove any existing `IRANUX_CERTIFICATION` block before editing.
2. Change `standard.schema_version` from `1.0` to `1.1`.
3. Add the required `ui` object.
4. Choose stable category and action IDs without numeric folder prefixes.
5. Select the most relevant canonical MDI icon.
6. Validate the exact icon name against the official Pictogrammers MDI catalogue.
7. Validate metadata, parameters, block counts, and final marker.
8. Request new certification when required.

## Before

```json
{
  "standard": {
    "name": "iranux-script-metadata",
    "schema_version": "1.0"
  },
  "script": {
    "id": "install-nginx",
    "name": "Install Nginx",
    "version": "1.0.0",
    "description": "Installs Nginx."
  },
  "risk": {
    "level": "medium"
  }
}
```

## After

```json
{
  "standard": {
    "name": "iranux-script-metadata",
    "schema_version": "1.1"
  },
  "script": {
    "id": "install-nginx",
    "name": "Install Nginx",
    "version": "1.0.0",
    "description": "Installs Nginx."
  },
  "risk": {
    "level": "medium"
  },
  "ui": {
    "category": {
      "id": "software-installation",
      "name": "Software Installation"
    },
    "action": {
      "id": "web-servers",
      "name": "Web Servers"
    },
    "icon": {
      "library": "mdi",
      "name": "web"
    }
  }
}
```

## What must not change automatically

Migration tools must not:

- rewrite the original Bash logic;
- add new input validation that changes behaviour;
- invent certification;
- sign the script;
- change parameter transport;
- remove existing parameters;
- change the final marker;
- silently choose an unverified icon name.

## Icon selection

Choose an icon based on the primary action rather than the broad category. Validate the canonical name before saving the migrated script.

The application-level fallback remains `script-text-outline`, but fallback must not be written over an invalid icon during validation.
